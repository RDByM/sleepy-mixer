# Sleepy Mixer: Rain Sounds — Tanıtım Sitesi (`web_tanitim`)

Canlı hedef adres: `https://rdbym.github.io/sleepy-mixer/`

## İçerik
- `index.html` — İngilizce / Türkçe geçişli, mobil uyumlu ürün vitrini + `MobileApplication` & `FAQPage` Schema.org JSON-LD
- `llms.txt` — ChatGPT, Perplexity ve arama botları için özet ürün kartı
- `robots.txt` & `sitemap.xml` — Arama motoru indeksleme dosyaları
- `.nojekyll` — GitHub Pages düz statik yayın ayarı
- `assets/icon.png` & `assets/og-preview.jpg` — Uygulama ikonu ve sosyal önizleme görseli

## Siteyi Güncelleme (Yönetim)
1. **Antigravity ile:** "Sitedeki başlığı / açıklamayı / görseli değiştir" demeniz yeterli; dosya güncellenip `git push` ile 30 saniyede yayına alınır.
2. **GitHub üzerinden:** `github.com/RDByM/sleepy-mixer` deposunda `index.html` dosyasını açıp sağ üstteki kalem (**Edit**) ikonuyla doğrudan tarayıcıdan güncelleyebilirsiniz.
